# Raw Rhythm

Personal daily-rhythm PWA: morning ritual, time-blocked timeline, dopamine tracker, daily permission.
Two scenarios (work day / dive day) plus a sprint mode. Data lives in `localStorage` only — nothing leaves the device.

Live: https://stephanetossens.github.io/raw-rhythm/

Inspired by the Raw Adventure method; this is a personal tool, not a Raw Adventure product.

## Stack

Single `index.html`, no build step.

- `manifest.webmanifest` — installable PWA (standalone, portrait)
- `sw.js` — app-shell precache, cache-first with background refresh; bump `VERSION` on every release
- `fonts/` — self-hosted Fraunces, Inter Tight, JetBrains Mono (latin + latin-ext) so the app works fully offline
- `icons/` — generated by `tools/make_icons.py` (Pillow)

## Deploy

GitHub Pages serves the `main` branch root. Push to `main` = deploy.

## Release checklist

1. Edit `index.html`.
2. Bump `VERSION` in `sw.js` (otherwise installed apps keep the old shell).
3. Commit, push.
